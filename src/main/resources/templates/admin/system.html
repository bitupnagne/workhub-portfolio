※ 개인이 직접 등록한 OTP는 정책과 무관하게 그대로 유지됩니다. 계정별 OTP 해제·초기화는 직원 관리에서 합니다.

업로드 허용 파일 형식(화이트리스트)

※ 업무 첨부파일에 적용됩니다. 실행파일·스크립트(exe·bat·js·sh 등)는 넣지 마세요. 차단 시 사용자에게 “허용되지 않은 파일 형식입니다. 필요 시 관리자에게 문의하세요.” 안내가 표시됩니다.

웹 테마 기본값 (조직 전체)

브랜드 색은 그대로 두고 배경/글자 대비만 전환합니다. 여기는 조직 기본값이며, 각 사용자는 상단바의 다크 모드 버튼으로 자기 화면을 개별 전환할 수 있습니다(사용자 선택 우선). ‘시스템’은 OS 설정을 따릅니다.
